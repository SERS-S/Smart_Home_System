---
name: curtain-control
description: Управление шторой ОБЛАКО: абсолютная открытость 0..100 через два доверенных shell-скрипта и mosquitto_pub.
---

Используй этот навык только для реальной просьбы изменить положение шторы.
Для отрицаний, цитат, гипотетических и справочных вопросов ничего не запускай.

0% — полностью закрыта, 100% — полностью открыта. Промежуточные целые проценты
разрешены. Для жалобы «слишком светло в комнате» обычная цель — 50%; явное
пожелание пользователя и достоверный текущий контекст важнее этого значения.
Не угадывай направление, если для него нужна неизвестная текущая позиция.

Перед запуском возьми request_id из последнего IVUS_REQUEST_CONTEXT.
Через параметр env инструмента exec передай IVUS_REQUEST_ID с этим значением.
Запусти ровно один из двух файлов, передав ровно один позиционный аргумент:

- Поднять: `{baseDir}/scripts/curtain-up.sh <целое 0..100>`.
- Опустить: `{baseDir}/scripts/curtain-down.sh <целое 0..100>`.

Не добавляй команды shell, перенаправления, цепочки, host, topic или API-ключи.
Скрипты уже знают конфигурацию. Не вызывай mosquitto_pub напрямую, common.sh,
интерпретаторы или любые другие исполняемые файлы.

Повтор одного действия в том же запросе возвращает ранее записанный результат;
другое действие в том же запросе запрещено. После ошибки не пробуй обходные
команды и не повторяй физическое действие с новым request_id.

Успех возвращает JSON с operation_id, level, topic и publish_status=published.
Это подтверждение брокера, а не завершение движения. Итоговый ответ:
«Команда поднять/опустить штору до N% открытости отправлена».
Если публикация не удалась, честно сообщи об ошибке.
